Turn on Web Push — one time setup

Push messages must be signed with a VAPID key pair. Generate one here, then paste both halves into Supabase. The private key never leaves this page except into your own Supabase secrets.

1
Generate your key pair
2
Store them as Edge Function secrets
In Supabase go to Project Settings → Edge Functions → Secrets and add: VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY and VAPID_SUBJECT (use mailto: and your email).
3
Create the Edge Function
Go to Edge Functions → Deploy a new function → Via Editor, name it send-push, paste the contents of edge-function-send-push.ts, and Deploy. No CLI or Docker needed.
4
Put the public key in the game
Open index.html and set PUSH.publicKey to the public key from step 1. Players will then be asked whether they want notifications.
5
Check the function is alive
This proves the secrets loaded and the keys import correctly. It sends nothing to anyone.
6
Send yourself a real one
Allow notifications in the game, then send to One player using your own username.
